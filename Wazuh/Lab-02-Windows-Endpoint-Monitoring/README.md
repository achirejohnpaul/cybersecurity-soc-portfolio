# Lab 02: Windows Endpoint Monitoring & Reconnaissance Detection

## 🎯 Objective
Simulate the reconnaissance phase of an attack and investigate how Wazuh captures endpoint activity. This maps directly to the early stages of the **MITRE ATT&CK** framework, where an attacker gathers information about a compromised system.

---

## 💻 Lab Environment

| Component | Value |
| :--- | :--- |
| **SIEM / EDR** | Wazuh |
| **Endpoint** | Windows 10 |
| **Attacker** | Windows 10 *(Simulated local attacker)* |
| **Target** | Windows 10 |
| **Goal** | Detect reconnaissance commands |
